Model Management Notes
  • Models are trained using the ml/train_models.py script and serialized as .pkl files.
  • To retrain: click the button above (runs in background) or run python ml/train_models.py from the command line.
  • Performance thresholds: Credit ROC-AUC ≥ 0.75, Fraud ROC-AUC ≥ 0.95, F1 ≥ 0.80 (NFR-02).
  • BR-07: models are auto-flagged for retraining if accuracy/recall drops below thresholds.
  • SHAP feature importance values are recomputed automatically on each training run.
